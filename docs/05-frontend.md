# Paraggi - STEP 5 - Frontend Mobile

L'app Expo e in `apps/mobile`.

## Stack

- React Native
- Expo
- TypeScript
- Expo Router
- Zustand
- TanStack Query
- React Hook Form
- NativeWind

## Schermate implementate

- Login
- Registrazione
- Feed vicino
- Composer post
- Dettaglio post/commenti
- Chat list
- Chat detail con stato geofenced
- Heatmap placeholder aggregata
- Cronologia aree
- Profilo/raggio/notifiche
- Privacy/export/delete account

## APK

Profilo EAS:

```bash
npm run mobile:build:apk
```

Genera un APK Android con `apps/mobile/eas.json` profilo `preview`.
